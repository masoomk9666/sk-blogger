AI-powered auto blogger with OpenAI, Gemini, Claude support, queue processing, image generation, and SEO.

== Installation ==
1. Upload the `sk-blogger` folder to `/wp-content/plugins/`.
2. Activate the plugin.
3. Go to **SK Blogger → Settings** and add your AI API keys.
4. Add topics to the queue and let the cron process them every 5 minutes.
